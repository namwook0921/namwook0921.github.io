Recover Homographies

computeH(im1_pts, im2_pts) · least squares
A.2
CS 180

Implement computeH(im1_pts, im2_pts). Show your correspondences visualized on the images, the system of equations, and the recovered homography matrix.

Me

Homographies map points from a plane to another plane viewed from a different angle or perspective. For each pair of (x,y) and (x',y'), computeH(im1_pts, im2_pts) wants to find the homography matrix H that projects (x,y) to (x',y') as accurately as possible. In practice, there isn't an exact solution for more than 4 points, so we find the least-squares solution of Ah = b, where A and b are constructed by stacking the rows shown below. The resulting h gives the entries of the homography matrix (H[3,3] is fixed to 1).

Two rows per correspondence (x, y) → (x′, y′)

xy1000−xx′−yx′000xy1−xy′−yy′ abcdefgh = x′y′
H = [[a, b, c], [d, e, f], [g, h, 1]] · stack all rows into A h = b and solve with np.linalg.lstsq

Warp the Images

inverse warping · nearest neighbor & bilinear
A.3
CS 180

Implement warpImageNearestNeighbor(im, H) and warpImageBilinear(im, H) using inverse warping. Apply to 2+ images for rectification. Show comparisons.

Me

We can now warp an image to match the reference plane's frame, or even warp both images to a certain plane we want, using the homography matrix. In warping, the coordinates don't map one-to-one onto pixels, so we implement nearest neighbor, which copies the nearest pixel's value, and bilinear, which takes the weighted average of the four neighboring pixels.

Blend the Images into a Mosaic

feathered weighted averaging
A.4
CS 180

Show 3 mosaics with source images. Use weighted averaging or blending to reduce edge artifacts. Explain your procedure.

Me

We keep the second image fixed and warp the first image into the second image's frame using the homography and the bilinear warp. Then, we size the canvas and take a weighted average of the two images for smooth blending. In particular, we use the feathering method.

namwook_lee Convolutions from Scratch

Four loops

def convolution_4d(img, kernel, padding=None):
    h, w = kernel.shape
    m, n = img.shape
    kernel = kernel[::-1,::-1]

    if padding == "same":
        pad_h = h // 2
        pad_w = w // 2
    elif padding == "full":
        pad_h = h - 1
        pad_w = w - 1

    img_pad = np.pad(img, ((pad_h, pad_h), (pad_w, pad_w)))

    h_out = img_pad.shape[0] - h + 1
    w_out = img_pad.shape[1] - w + 1

    img_out = np.zeros(shape=(h_out, w_out))

    for i in range(h_out):
        for j in range(w_out):
            val = 0
            for k in range(h):
                for l in range(w):
                    val += kernel[k][l] * img_pad[i+k][j+l]
            img_out[i][j] = val

    return img_out

The four-loop convolution does a 2D loop across the offset of the kernel to the image's origin, and does another 2D loop inside it across each element of the kernel. For a random 3×3 kernel, it takes 73.2 seconds.

Two loops

def convolution_2d(img, kernel, padding=None):
    h, w = kernel.shape
    m, n = img.shape
    kernel = kernel[::-1,::-1]

    if padding == "same":
        pad_h = h // 2
        pad_w = w // 2
    elif padding == "full":
        pad_h = h - 1
        pad_w = w - 1

    img_pad = np.pad(img, ((pad_h, pad_h), (pad_w, pad_w)))

    h_out = img_pad.shape[0] - h + 1
    w_out = img_pad.shape[1] - w + 1

    img_out = np.zeros(shape=(h_out, w_out))

    for i in range(h_out):
        for j in range(w_out):
            img_out[i][j] = np.sum(kernel * img_pad[i:i+h,j:j+w])

    return img_out

The two-loop convolution reduces this by replacing the latter loop with an element-wise multiplication. For a random 3×3 kernel, it takes 47.3 seconds.

namwook_lee Derivative of Gaussian Filter

Gaussian Blur → (D_x² + D_y²) is exactly equal to (DoG_x² + DoG_y²) because convolution is associative. Numerically, max pixel difference between the two images constructed by blur → convolution vs DoG convolution is 3.74e-16.

Part 2.1
Sharpened
Gaussian blur

The unsharp masking is done by applying I + alpha * (I - G), where I is the identity operation and G is the Gaussian blur. Applying G to the image results in lowering the frequency, and deleting most of the high frequency details, so that the image is blurred.

Subtracting the Gaussian from the original image, therefore leaves the high frequency details, while reducing the low frequency aspects of the image.

(Click to zoom)

As (I - G) applied to the image leaves the high frequency details of the image, adding this to the original image results in a sharpened version of the image. This is how the unsharpen mask works, and above is a result of sweeping alpha, a constant multiplied to (I - G) when sharpening the image. Higher alpha leads to a more exaggerated sharpening of the image.
